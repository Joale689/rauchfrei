# Rauchfrei

Eine persönliche Progressive Web App zur schrittweisen Rauchentwöhnung.

## Idee

Das Projekt entstand aus einem konkreten eigenen Bedarf: Mein Zigarettenkonsum sollte nicht nur gezählt, sondern auch bei wechselnden Arbeits- und Schlafzeiten sinnvoll erfasst werden können.

Die Anwendung bildet deshalb keinen einfachen Kalendertag ab, sondern arbeitet mit einer eigenen Rauchtag-Logik, die sich an meinem Tagesablauf und Schichtsystem orientiert.

## Funktionen

- Erfassung von Zigaretten und Dampfen
- schrittweise Reduktion des Zigarettenkonsums
- eigene Tageslogik für wechselnde Schichten
- lokale Datenspeicherung
- Import und Export der Daten
- Rückgängig-Funktion
- Anzeige des aktuellen Tagesstands
- Nutzung als installierbare Progressive Web App
- Offline-Nutzung über Service Worker

## Hintergrund

Die Anwendung wurde über mehrere Versionen schrittweise erweitert und an der tatsächlichen Nutzung angepasst.

Ein besonderer Schwerpunkt lag darauf, die Tageszuordnung trotz Schichtarbeit sinnvoll abzubilden. Dabei mussten unter anderem unterschiedliche Tagesanfänge und Ereignisse rund um die Tagesgrenze berücksichtigt werden.
